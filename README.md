# 马里奥学习系统

当前版本：**v1.0.62**。

v1.0.62：统一改为 R1 / Xbox RB 逐层返回、R2 / Xbox RT 切换全屏。
R1 不再刷新炸弹迷宫或滚动学习页，L2 / LT 保留菜单滚动，摇杆边缘滚动不变。
按住、重连、失焦或捕捉快捷键期间不误触发；全屏不会自动打开游戏设置。
网页更新后刷新即可，不需要编译或重启服务。

v1.0.61：R2 / Xbox RT 改为逐层返回：情景内容 → 情景选择 → 首页；
主题内容 → 小主题列表 → 系列列表 → 首页，Book1 内容 → 字母组 → 首页。
按住不连续返回；全屏中返回保留全屏。炸弹迷宫先收起当前子设置、设置或
菜单光标，再返回首页；全屏仍可用设置里的“全屏”按钮切换。
手柄电量直接显示在炸弹迷宫设置中，删除静态操作说明。Windows Xbox / XInput
通过本地只读接口显示没电、低、中、满；有线或设备不提供时显示未知，不伪报
百分比。PS5 仍需 WebHID 授权。更新后需重启本地 Python 服务一次以加载
电量接口，再刷新网页；浏览器存档和其他学习规则不变。

v1.0.43：炸弹迷宫的攻击设置增加 PS5 手柄电量。点击“读取手柄电量”后
在浏览器设备选择器中授权 DualSense / DualSense Edge；已有单一授权会恢复读取。
仅监听完整 HID 输入报告，电量按设备的十个百分点档位显示（例如 60–69%），
同时标注充电中、已充满和低电量。取消授权、断线、数据过期、不支持 WebHID
或蓝牙只给简短报告时显示“未知”，不使用电脑电量、不发送手柄输出/特征指令，
不改变移动、攻击或任何进度。推荐 Edge / Chrome；真实手柄读取需用户授权验证。

v1.0.42：八个系统页面增加仅在网页内活动的手柄光标。学习页面左/右摇杆
移动光标，A / ×（或按下右摇杆）点选，LB / RB 滚动页面或横向列表。
炸弹迷宫左摇杆保留角色移动，右摇杆或 Y / △ 打开菜单光标；菜单期间暂停
游戏，A / × 点选，Y / △ 或点击画布返回游戏。支持网页按钮、SVG 热点、
滑条和下拉选项；光标限于页面视口，虚拟点选不打开外链、下载或新标签页。
连接、失焦和断线后须松键、摇杆回中；不保存手柄状态、不改学习进度规则。
这不是 Windows 鼠标或系统锁定模式，真实鼠标、键盘和浏览器功能仍可正常使用。

v1.0.41：炸弹迷宫支持标准手柄。左摇杆 / 十字键移动，A / × 投小蘑菇，
B / ○ 放冰炸弹；开始、继续和下一关等待画面用 A / × 或 Start / Options
确认，确认不会同时攻击。攻击只在新按下触发，受伤、失焦、断线、菜单和
重连后须回中松键才重新接受输入；键盘操作及存档保持不变。连接后先按一下
手柄按钮让浏览器识别；非标准映射请切换 XInput 模式。手柄帮助和连接状态
显示在开场卡与攻击设置内。浏览器音频若未解锁，请先用鼠标点一次开始。
