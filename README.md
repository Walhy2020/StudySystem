# 马里奥学习系统

当前版本：**v1.0.35**。

炸弹迷宫双攻击：默认空格投小蘑菇（伤害 1），B 释放冰炸弹；可在攻击设置改键。
冰炸弹初始容量 1、长度 2，冻结敌人 3 秒；每关各有一个冰花（长度 +1）和
冰炸弹道具（同时释放容量 +1）。普通怪物血量 3、库巴 50；库巴每 3 秒
朝当前朝向吐火球，无需看到玩家。火球打开撞到的第一块砖并消失，库巴
会自由走动；头顶圆环显示冷却。导弹原有红/黑特殊炸弹规则保持不变。

跨电脑继续开发时，请先阅读：

- `AGENTS.md`：长期开发规则、模块边界和验收要求
- `PROJECT_HANDOFF.md`：当前交付状态、公司电脑初始化及接手步骤
- `CODEX_COLLABORATION.md`：主会话、各模块子会话及跨电脑协作方式

当前重构阶段包含：

- 汉字学习与复习模块
- 独立的炸弹迷宫学习游戏（3～6 世界，每世界 5 关，共 20 关）

双击 启动马里奥学习系统.bat，或运行：

    python server.py --bind 127.0.0.1 --port 5177

访问 http://127.0.0.1:5177/，可从主页面进入炸弹迷宫。

检查与测试：

    npm run check
    npm test
    npm run test:browser
