# 马里奥学习系统

当前版本：**v1.0.41**。

v1.0.41：炸弹迷宫支持标准手柄。左摇杆 / 十字键移动，A / × 投小蘑菇，
B / ○ 放冰炸弹；开始、继续和下一关等待画面用 A / × 或 Start / Options
确认，确认不会同时攻击。攻击只在新按下触发，受伤、失焦、断线、菜单和
重连后须回中松键才重新接受输入；键盘操作及存档保持不变。连接后先按一下
手柄按钮让浏览器识别；非标准映射请切换 XInput 模式。手柄帮助和连接状态
显示在开场卡与攻击设置内。浏览器音频若未解锁，请先用鼠标点一次开始。

v1.0.40：小蘑菇碰到砖块会停止，不再打碎砖块，攻击敌人仍为 1 点伤害。
库巴火球显示尺寸扩大两倍，取消飞行时间和射程上限，发射 CD 改为 2 秒；
仍在地图边界、墙、第一块砖、炸弹或玩家处结束，不穿墙。旧存档保留关卡、
血量和道具，已有火球继续飞行；绿色冷却环保持不变。

v1.0.39：新拼音固定教材顺序（声母 → 韵母 → 整体认读音节）。新开一轮
从目录开头筛选，已完全认识项仍跳过；今日新拼音的学习不再随机，旧存档
按顺序继续未完成项且保留已完成记录。复习、临时复习和其他模块规则不变。

v1.0.38：在汉字左侧增加独立“拼音”页。收录 23 声母、24 韵母和 16 整体
认读音节，每次只显示一项，不附汉字、拼读例子或关联词。沿用音标的筛选、
√/×/★、单遍学习确认完成、全量非完全认识复习及错项修复；刷新继续，进度
仅保存到 mario-pinyin-v1。此页不使用汉字代读拼音，也不调用英语字母 TTS。
窄屏模块导航可横向滑动，原模块顺序保持不变。

v1.0.37：修复小蘑菇连续投掷被“三发在途”限制吞掉的问题；恢复存档和
投掷/更新时过滤已经结束或异常的蘑菇弹道，不重置关卡、血量、冰炸弹或改键。
真实 Edge 定向检查覆盖三种主角、连续投掷、刷新继续、弹道回收、改键与冰炸弹。

炸弹迷宫双攻击：默认空格投小蘑菇（伤害 1、不打晕或中断怪物移动），B 释放冰炸弹；可在攻击设置改键。
冰炸弹初始容量 1、长度 2，冻结敌人 3 秒；每关各有一个冰花（长度 +1）和
冰炸弹道具（同时释放容量 +1）。普通怪物血量 3、库巴 40；库巴每 2 秒
朝当前朝向吐火球，无需看到玩家。火球打开撞到的第一块砖并消失，库巴
会自由走动；火球显示尺寸为原来的两倍、无飞行时间或射程上限，头顶绿色
圆环显示冷却。导弹原有红/黑特殊炸弹规则保持不变。

跨电脑继续开发时，请先阅读：

- `AGENTS.md`：长期开发规则、模块边界和验收要求
- `PROJECT_HANDOFF.md`：当前交付状态、公司电脑初始化及接手步骤
- `CODEX_COLLABORATION.md`：主会话、各模块子会话及跨电脑协作方式

当前重构阶段包含：

- 汉字学习与复习模块
- 独立的炸弹迷宫学习游戏（3～6 世界，每世界 5 关，共 20 关）

双击 启动马里奥学习系统.bat，或运行：

    python server.py --bind 127.0.0.1 --port 5177

访问 http://127.0.0.1:5177/，可从主页面进入炸弹迷宫。

检查与测试：

    npm run check
    npm test
    npm run test:browser
