# What Is It? 独立文具强调图 v1

用途：第二情景对话提到具体物品时，在教室黑板中央的白色圆形底上单独放大显示。

共同要求：

- 儿童英语教材风格的精致 3D 卡通文具，视角、光照和饱和度保持一致。
- 透明背景 RGBA PNG，不带文字、人物、桌面、黑板、白色圆底或其他文具。
- 主体完整、轮廓清楚、居中并留出安全边距，适合 `object-fit: contain`。
- 数量和颜色必须严格准确。

生成的五个正式资源：

1. `focus-pen-v1.png`：一支蓝色圆珠笔。
2. `focus-yellow-pencils-v1.png`：三支黄色木杆铅笔。
3. `focus-red-marker-v1.png`：一支红色马克笔。
4. `focus-green-erasers-v1.png`：三块绿色橡皮。
5. `focus-red-erasers-v1.png`：三块红色橡皮。

白色圆底、阴影和弹出动画由 `scenario-learning.css` 绘制，不写入图片本身。
