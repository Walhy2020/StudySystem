## 公司电脑如何继续

1. 在干净工作区更新 main，把仓库根目录设为 Codex 项目的主要文件夹。
2. 建一个主聊天，选择 GPT-6.1 Sol／高，先读 AGENTS.md、PROJECT_HANDOFF.md、CODEX_COLLABORATION.md 和本文。
3. 如需保留独立模块聊天，按表中原名称建立七个聊天，各选 GPT-6 Astra／中，职责以本文为准。手动聊天的模型需在应用中选择，模板不会修改它们。
4. 只在用户明确安排跨聊天协作时派发任务；主聊天统一整合共享文件，避免多个聊天同时写同一文件。独立聊天不会因为命名而自动成为父子会话。
5. 每次切换电脑，先检查 Git 状态再更新代码；未提交的修改必须先处理，不覆盖本地工作。

主聊天启动词：

> 请读 AGENTS.md、PROJECT_HANDOFF.md、CODEX_COLLABORATION.md 和 docs/codex/README.md，检查 Git 状态，从当前 main 继续。你负责整合与发布，只在我明确要求时协调子会话；只做与本次修改相关的浏览器验证，按仓库规则更新版本并提交推送。

## 可选：内部子代理配置

本目录中的 TOML 是未自动启用的模板；它们不是桌面独立聊天的导入文件。

- 将 config.template.toml 的字段合并到项目 .codex/config.toml，不覆盖已有配置。
- 如需命名的内部子代理，将 agents/ 下所需 TOML 复制到项目 .codex/agents/。
- 配置会为之后的内部子代理设置 Astra／中，不会恢复七个旧桌面聊天，也不会更改已运行聊天的模型。
- 模型是否可选取决于公司电脑账号和客户端支持；缺失时报告，不默默替换。

字段按 [OpenAI 官方子代理文档](https://developers.openai.com/codex/subagents) 核对。模板不设置权限、密钥或机器路径。

## 不通过 Git 同步的内容

旧聊天历史与父子指针、账号登录、API Key、技能安装、浏览器学习进度、蓝牙/USB驱动、WebHID授权。不要复制整个用户 .codex 或浏览器资料目录进仓库。

Git 保存代码、协作分工、模型快照和可复用模板；它不能保证另一台电脑自动出现完全相同的聊天环境。
